# Federated Identity Chaining Lab

## Project Overview

This hands-on lab demonstrates Federated Identity Authentication using Auth0 and LinkedIn.

## Technologies Used

- Auth0
- LinkedIn Identity Provider
- OAuth 2.0
- OpenID Connect (OIDC)
- JSON Web Token (JWT)

## Authentication Flow

1. User selects Login with LinkedIn.
2. Auth0 redirects authentication to LinkedIn.
3. LinkedIn validates user identity.
4. Auth0 receives authentication response.
5. User gets authenticated access to the application.

## Key Learning Outcomes

- Understanding Identity Federation
- OAuth 2.0 authentication
- OpenID Connect
- Single Sign-On (SSO)
- Token-based authentication
